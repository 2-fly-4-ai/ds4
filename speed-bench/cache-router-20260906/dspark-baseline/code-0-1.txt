Here's a Python function to add two integers:

```python
def add(a, b):
    """
    Add two integers and return their sum.
    
    Args:
        a (int): First integer
        b (int): Second integer
    
    Returns:
        int: The sum of a and b
    """
    return a + b
```

**Brief explanation:**

- The function `add(a, b)` takes two parameters `a` and `b`.
- It uses the `+` operator to add them together.
- The `return` statement sends the result back to the caller.
- The docstring (triple-quoted string) provides documentation about the function's purpose, parameters, and return value.

**Example usage:**
```python
result = add(5, 3)
print(result)  # Output: 8
```

This is a simple, straightforward function that demonstrates basic Python syntax for defining functions, parameters, and returning values.

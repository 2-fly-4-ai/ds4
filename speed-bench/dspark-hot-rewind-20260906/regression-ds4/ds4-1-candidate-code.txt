Here's a Python function to add two integers:

```python
def add(a, b):
    """
    Add two integers and return their sum.
    
    Args:
        a (int): First integer
        b (int): Second integer
    
    Returns:
        int: The sum of a and b
    """
    return a + b
```

- The function `add(a, b)` takes two parameters `a` and `b`.
- It simply returns their sum using the `+` operator.
